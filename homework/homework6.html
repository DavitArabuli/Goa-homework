2. HTML and programing:

1. რა არის HTML და რისთვის გამოიყენება? HTML არის ენა, რომლის საშუალებითაც ვქმნით ვებგვერდის სტრუქტურას. მისი დახმარებით ვამატებთ სათაურებს, ტექსტებს, სურათებს, ბმულებს და სხვა ელემენტებს.
2. რა განსხვავებაა Empty და Container თეგებს შორის? Container თეგს აქვს გამხსნელი და დამხურავი თეგი და მასში შეგვიძლია ჩავწეროთ სხვა ელემენტები ან ტექსტი. Empty თეგს არ აქვს დამხურავი თეგი და მასში ტექსტს ვერ ვათავსებთ.
3. რა განსხვავებაა Frontend-სა და Backend-ს შორის? Frontend არის ვებგვერდის ის ნაწილი, რომელსაც მომხმარებელი ხედავს და იყენებს, მაგალითად, ღილაკები, ტექსტები და დიზაინი. Backend კი არის ვებგვერდის შიდა ნაწილი, რომელიც ამუშავებს მონაცემებს და უზრუნველყოფს მის სწორ მუშაობას.
